# Bitcoin Price Application

This Python application fetches the current price of Bitcoin in multiple currencies (USD, GBP, and EUR) using the CoinDesk API and displays it based on user input.

## Features

- Displays Bitcoin's current price in USD, GBP, and EUR.
- Simple text-based interface allowing users to choose the currency they want to view.
- Fetches real-time data from the CoinDesk API.

## Requirements

Make sure to have Python installed along with the necessary packages. You can install the required dependencies using `requirements.txt`.

### Install dependencies:
Run the following command to install the required packages:

```bash
pip install -r requirements.txt
